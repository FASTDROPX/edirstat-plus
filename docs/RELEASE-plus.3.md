# eDirStat Plus v2.2.0-plus.3

GPU-отрисовка мелких файлов, кэш диска и плавная навигация.

## Изменения

- Градиенты и обводки мелких файлов перенесены с CPU на GPU: экземпляры прямоугольников вместо полной картинки на каждом изменившемся кадре. GPU-буферы переиспользуются; в неподвижном кадре список плиток не загружается заново.
- Убраны ненужные вычисления геометрической анимации мелких плиток.
- Добавлен постоянный кэш диска: сохранённое дерево показывается до фоновой проверки свежим MFT, после чего данные обновляются. Проверка пока полная, без NTFS USN.
- Плавный вход в папку двойным кликом с адаптацией внутренней раскладки к пропорциям окна и возвратом к родительской карте.
- Зум и выход из папки работают через Ctrl+колесо. Обычное колесо не выводит из открытой папки.
- Стабильная форма при обычном зуме, режимы мягких анимаций/цветов/без анимаций, защищённые заголовки папок, исправления слоёв и плотного заполнения.
- Минимальная плитка: пиксель содержимого с обводкой вокруг; пофайловые границы чуть темнее цвета плитки.
- Таблица папок использует доступную ширину.

## Производительность и проверка

QHD 2560×1440, синтетическая карта, стиль Cushion, медиана 9 повторов:

| Плитки | Подготовка на CPU раньше | Теперь | Ускорение этапа |
|---|---:|---:|---:|
| 409 440 по 3×3 px | 38,296 мс | 8,766 мс | 4,37× |
| 147 456 по 5×5 px | 32,756 мс | 3,243 мс | 10,10× |

Это замер подготовки мелких плиток на CPU, без раскладки, исполнения GPU и вывода кадра. Общее ускорение/FPS не измерены. Чтение MFT этим переносом не ускоряется.

Offscreen-проверка на NVIDIA RTX 5060/Vulkan: 27 изображений (9 стилей × DPI 1/1,25/2), дробные координаты, обрезка, разные стадии анимации. Совпадение с CPU в пределах 1/255 на канал. Release-сборка прошла; полный набор тестов для этого релиза повторно не запускался. Подробности и ограничения сравнения — в CPU-GPU-REPORT.md и отчёте внутри архива.
