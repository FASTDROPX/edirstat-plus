# eDirStat Plus v4 — новый интерфейс и автоматический кэш

## Интерфейс

- Главная страница с дисками, выбором папки, открытием снимка, вводом пути и недавними папками.
- Боковая навигация: обзор диска, графики, дубликаты, очистка, Docker и статистика. Переход в настройки и на главную сохраняет открытый анализ.
- Отдельный экран настроек: оформление, рабочее пространство, сканирование и файлы, клавиатура. Изменения сохраняются автоматически.
- Системная, тёмная, светлая и контрастная темы; три цвета акцента оболочки.
- Компактная навигация для узкого окна, векторные значки, экран подготовки анализа, прогресс MFT, остановка и копирование пути.

## Кэш

Кэш **включён по умолчанию**. После успешного сканирования снимок сохраняется автоматически. При следующем запуске последний доступный сохранённый путь выбирается сам, снимок открывается, затем изменения проверяются в фоне.

В **Настройки → Сканирование и файлы → Кэш диска** можно отключить чтение и новые сохранения кэша. Настройка сохраняется. Уже открытый анализ и старые снимки при отключении не удаляются. Проверка актуальности пока выполняет полное повторное чтение MFT, без инкрементального NTFS USN.

## Дерево

Раскладка, GPU-отрисовка, детализация, зум и переходы папок сохранены из v3. **Ctrl+колесо** — зум и выход из открытой папки. Палитра карты настраивается отдельно от темы оболочки.

## Скачать

- **edirstat-plus-v4.exe** — portable Windows x64, без установки.
- **edirstat-plus-v4-windows-x64.zip** — exe, SHA256, инструкция, патч, журналы и снимки интерфейса.
- **edirstat-plus-v4.sha256.txt** — контрольная сумма exe.
- **UX-V4.md** — подробная инструкция.

Требуется Microsoft Visual C++ Runtime x64. Неофициальная доработка eDirStat, базовая внутренняя версия приложения — 2.2.0.

## Статус UX Preview и проверка

В заголовке окна остаётся **UX Preview**. Используется отдельный профиль настроек и кэша **eDirStat UX Preview**; данные профиля v3 автоматически не переносятся. Новые главная/настройки пока на русском. Существующие компоненты сохраняют свои переводы. Предыдущий релиз v2.2.0-plus.3 остаётся доступен.

Windows x64 Release-сборка прошла. Оболочка проверена 17 offscreen GPU-снимками: ширины 800/1280 px, тёмная/светлая/контрастная темы, категории настроек, MFT-загрузка и рабочее пространство с синтетическими данными. Проверены ширина страниц, история путей и сериализация настроек. Для последующей небольшой правки переключателя кэша выполнена только сборка, без новых тестов по просьбе пользователя. Полный набор тестов и ручное сканирование реального диска из новой оболочки не запускались.
