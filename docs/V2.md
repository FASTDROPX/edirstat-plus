# eDirStat Plus · v2

Запускайте **edirstat-plus-v2.exe**. Сборка Windows x64 Release, Microsoft Visual C++ Runtime x64.

## Карта

- **По файлам** — отдельные блоки файлов внутри папок. Убрано сворачивание плотных папок по прежнему порогу 16 пикселей² на файл. На тесте папки с 2000 файлами все 2000 положительных по размеру файлов представлены отдельными блоками.
- **По папкам** — обзор непосредственных подпапок текущего корня карты. Двойной щелчок открывает папку подробнее. Файлы непосредственно в корне также видны.
- **Ctrl + колесо вверх** приближает карту к курсору, вниз — отдаляет. Масштаб меняется плавно, новые блоки проявляются за 0,18 секунды. При приближении появляются более мелкие элементы. Масштаб до 4096×.
- При увеличении карту можно перемещать перетаскиванием. **Сбросить зум** возвращает 100%.
- Палитры расширений и папок: **Пастельная**, **Насыщенная · WizTree**, **Океан**, **Тёплая**, **Монохромная**. Числовые карты размера/возраста сохраняют собственную шкалу, чтобы легенда оставалась верной.
- Стилей теперь девять: четыре исходных градиентных/рельефных, плоский, **Объёмные плитки**, **Стекло**, **Неон**, **Контуры**. Выбор — меню «Вид» → стиль древовидной карты.
- ПКМ по объекту: **Показать в проводнике**, **Удалить…**. Удаление использует существующие настройки подтверждения и фоновую обработку. Во время сканирования удаление из карты отключено, чтобы не применять действие к меняющимся индексам дерева.

Файлы нулевого размера не имеют площади на пропорциональной карте. У элементов меньше экранного пикселя и у слишком большого числа видимых блоков сохраняются ограничения детализации — приближайте нужную область или открывайте папку двойным щелчком. Карта не пытается рисовать миллионы невидимых объектов за каждый кадр.

## Сканирование

- Скорость подписана **Индексация**, рядом отображаются файлы/с. Это объём найденных файлов / время работы сканера, а не скорость чтения содержимого диска.
- Байты прочитанных метаданных MFT отделены от суммарного размера файлов. Исправлена гонка запуска, при которой интерфейс мог преждевременно завершить таймер. Время завершения берётся у координатора.
- Корневые папки публикуются раньше. Частота последующих снимков адаптируется к их стоимости; расчёт бюджета — приблизительный механизм ограничения накладных расходов, а не гарантия нулевого замедления.
- В «Вид» есть **Живое дерево во время сканирования**. Его можно отключить для минимальных накладных расходов. Во время работы новые видимые имена строк появляются плавно.
- При MFT-сканировании сначала строится индекс метаданных. В этой фазе имена папок ещё недоступны интерфейсу; отображается статус чтения MFT. Частичное дерево поступает после построения индекса. Это не потоковая визуализация файлов до окончания первой MFT-фазы.

На локальном тестовом дереве из 6000 файлов и 61 папки, после прогрева кэша, медиана пяти замеров: предыдущая сборка **8,46 мс**, новая **7,63 мс**. Такой небольшой тест не доказывает ускорение сканирования терабайтного диска или raw MFT. Результаты сохранены в BENCHMARK-v2.json; гарантированное ускорение полного диска не заявляется.

## Запрос прав администратора

Окно заменено на ограниченный по ширине, изменяемый по размеру диалог. Ошибка или отмена повышения прав больше не игнорируется. Добавлена выключенная по умолчанию настройка **Всегда автоматически запрашивать права администратора при запуске** — в диалоге и меню «Вид».

При включении настройка сохраняется. На следующих запусках приложение запрашивает обычный UAC, если ещё не запущено с повышенными правами. При отмене можно продолжить без повышения прав. UAC не обходится, настройки безопасности Windows не меняются. Реальное повышение прав и удаление пользовательских файлов в проверках не выполнялись.

## Проверка

- `cargo build --release` завершён успешно, stable Rust 1.100.0, MSVC x64.
- 118 тестов ядра, 149 GUI и 11 координатора прошли. В GUI исключён прежний тест симлинков из-за WinError 1314; для native-крейта запускалась выбранная группа координатора, а не все тесты.
- Проверены плотные папки, геометрия зума, отсечение невидимых файлов, 45 сочетаний палитр/стилей, сериализация настроек, раннее появление частичного дерева и итоговый размер файлов независимо от MFT-байтов.
- Версия и сканирование тестового дерева проверены готовым exe; PE32+ AMD64 проверяется при упаковке.
- Новые функции проверялись кодом и headless-тестами; физический Ctrl+колесо, окно UAC и новые стили в настоящем окне вручную не проверялись. После остановки Computer Use управление рабочим столом не возобновлялось.
